# 🚗 Self-Driving Car AI

An educational self-driving car simulation built to understand how **neural networks** and **machine learning** enable autonomous decision-making.  
The car learns how to navigate a road, avoid obstacles, and stay within lanes using real-time sensor data.

This project focuses on **learning core AI concepts**, not real-world vehicle deployment.

---

## 🎯 Project Goal

The main goals of this project are to:
- Understand how self-driving systems perceive their environment
- Learn how neural networks make driving decisions
- Simulate autonomous vehicle intelligence in a controlled environment

---

## 🧠 How the Neural Network Works

Each car is controlled by a neural network that processes sensor inputs and outputs driving actions.

## 🧬 Learning Method

The car learns using **evolutionary learning (genetic algorithm)**:

1. Multiple cars are spawned with random neural networks
2. Cars are evaluated based on distance traveled and collision avoidance
3. Best-performing networks are selected
4. New generations are created through mutation
5. Driving performance improves over generations
